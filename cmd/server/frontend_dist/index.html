SpotiFLAC web

This is the committed placeholder. The real bundle is generated by the build pipeline.

To build locally:

./scripts/build-web.sh

Or manually:

cd frontend && pnpm install && pnpm run build
rm -rf ../cmd/server/frontend_dist/*
cp -r dist/. ../cmd/server/frontend_dist/
go build -o ../spotiflac-server ../cmd/server

The contents of cmd/server/frontend_dist/ are gitignored except for this file, so generated bundles will not accidentally be committed.
